# fonts

The code fonts Baude and Record offer in Settings → Code Font, found through FontConfig (`fontsetup.py`). JetBrains
Mono is the default. Each is under the SIL Open Font License 1.1, its licence beside it as `OFL.txt`.

| Font | Files | From |
|---|---|---|
| JetBrains Mono | `JetBrainsMono/` (variable: weight; upright, italic) | [google/fonts](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono) |
| IBM Plex Mono | `IBMPlexMono/` (regular, italic, bold) | [google/fonts](https://github.com/google/fonts/tree/main/ofl/ibmplexmono) |
| Fira Code | `FiraCode/` (variable: weight) | [google/fonts](https://github.com/google/fonts/tree/main/ofl/firacode) |
| Source Code Pro | `SourceCodePro/` (variable: weight; upright, italic) | [google/fonts](https://github.com/google/fonts/tree/main/ofl/sourcecodepro) |
| Geist Mono | `GeistMono/` (variable: weight; upright, italic) | [google/fonts](https://github.com/google/fonts/tree/main/ofl/geistmono) |
| Cascadia Code | `CascadiaCode/` (variable: weight; upright, italic) | [google/fonts](https://github.com/google/fonts/tree/main/ofl/cascadiacode) |
| Inconsolata | `Inconsolata/` (variable: width, weight) | [google/fonts](https://github.com/google/fonts/tree/main/ofl/inconsolata) |
| CommitMono | `CommitMono/` (400 and 700; upright, italic) | [CommitMono 1.143](https://github.com/eigilnikolajsen/commit-mono/releases/tag/v1.143) |
