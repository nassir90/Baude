Baude

mpts.ie / apps

A desktop app for Claude Code, built with GTK 4 and libadwaita. It runs the claude command you already have and shows everything it does: replies as they stream in, tool calls you can read, permission prompts, subagents and background tasks, and every session on your computer, including the ones running in Claude Desktop or a terminal, which it follows live.

How it works

Baude doesn't talk to the API itself. It runs one long-lived claude -p process and speaks its stream-json protocol, the same one the Agent SDK uses. Everything agentic (tools, permissions, context, compaction, MCP, hooks, skills, CLAUDE.md, sessions) stays the CLI's job, so Baude works with your existing sign-in, settings and plugins. Baude is the view.

Sessions are the CLI's own transcripts, so Baude lists every one on the computer. A session another program is writing is followed like tail -f, and Baude keeps its own input off until that program is done. It is plain Python whose only dependency is PyGObject.
